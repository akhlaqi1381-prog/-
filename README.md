# # 🎬 سیستم پیشنهاددهنده فیلم

این پروژه یک سیستم پیشنهاددهنده فیلم است که با استفاده از دو روش مختلف، فیلم‌های مناسب را به کاربران پیشنهاد می‌دهد:

### 1. Content-Based Filtering
در این روش، ویژگی‌های خود فیلم‌ها مانند ژانر و تگ‌ها بررسی می‌شوند و فیلم‌هایی که از نظر محتوایی مشابه هستند به کاربر پیشنهاد داده می‌شوند.

### 2. User-Based Collaborative Filtering
در این روش، رفتار و امتیازدهی کاربران بررسی می‌شود. ابتدا کاربران مشابه یک کاربر مشخص پیدا شده و سپس فیلم‌هایی که کاربران مشابه دیده یا امتیاز داده‌اند، به عنوان پیشنهاد ارائه می‌شوند.

## 🎯 هدف پروژه

هدف این پروژه، پیاده‌سازی و مقایسه دو رویکرد رایج در سیستم‌های پیشنهاددهنده و بررسی نحوه استفاده از اطلاعات فیلم‌ها و رفتار کاربران برای تولید پیشنهادهای شخصی‌سازی‌شده است.

## 📁 Dataset

داده‌های مورد استفاده از مجموعه‌داده **MovieLens** شامل اطلاعات فیلم‌ها، امتیازات کاربران و تگ‌ها هستند.
